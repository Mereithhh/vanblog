VanBlog 可以配置一系列的站点配置项，可在 `站点管理/系统设置` 中查看。

包括三类：

- 基本设置：博客系统正常运行必须的配置
- 高级设置：博客系统的进阶选项
- 布局设置：改变前台展示布局的设置（含每页文章数、友链页 / 关于页文案、导航栏左侧显示网站名或 logo）。手机端顶栏网站名相对整页宽度居中，电脑端仍在左侧。

所有设置项详见 [参考 → 站点配置](../reference/config.md)。
