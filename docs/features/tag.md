你可以在 VanBlog 的管理后台中轻松对分类和标签进行管理。

<!-- more -->

## 分类管理

分类管理位于后台的 `站点管理/数据管理/分类管理`:

![分类管理](https://pic.mereith.com/img/557dd4cdc00fa700179b34a8ed354291.clipboard-2023-01-28.png)

你可以:

- 新建分类

- 查看分类: 可直接跳转到博客的对应页面查看相关分类的文章。

- 重命名: 对分类进行重命名。文章和草稿存的是分类名，重命名会同步改写所有使用旧名称的文章和草稿，前台分类页与后台列表都会显示新名称。

  ![重命名分类](https://pic.mereith.com/img/c9ae290254e9e0011137b8c988c6fd1a.clipboard-2023-01-28.png)

- 分类排序

  分类管理表格有「排序」列，可用「上移 / 下移」调整分类顺序，不必删除再重建。前台导航分类子菜单、分类列表和分类页会按这个顺序展示。隐藏分类仍出现在后台列表里并参与排序，但不会出现在前台；可见分类之间保持相对顺序。已有文章的分类也可以直接改顺序。

- 分类页展开

  前台分类列表（`/category`）每一行都可以点：分类名、篇数或右侧 `>` 箭头都会展开 / 收起该分类下的文章。展开后箭头旋转成 V，不再用容易看成「新增文章」的 `+`。页上还有「全部展开 / 全部收起」。后台 **站点配置 / 布局设置** 的「分类页默认展开全部分类」决定第一次打开时是全收起还是全展开，默认仍是全收起。点进某一个分类、标签页和时间线不受这项设置影响。

- 隐藏分类

  分类管理表格有「是否隐藏」列（开关显示「是 / 否」），也可在「重命名」弹窗里改同一字段。隐藏后，前台分类列表、导航分类子菜单、分类页和 sitemap 不再展示该分类；后台列表仍能看到。该分类下的文章仍按各自的「是否隐藏 / 加密」规则展示，不会因为分类隐藏而被额外加密。

  ::: note

  隐藏分类和加密分类不同：加密只锁正文，分类入口仍在；隐藏则从前台分类入口拿掉。

  :::

- 加密分类

  加密某个分类后，此分类下的所有文章都会被加密。密码以分类的密码为准。

  ::: note

  加密后，访客仍可正常访问分类并获取文章列表。

  :::

- 删除分类

  ::: note

  删除某个分类的前提是该分类下的文章已经全部被删除，否则 VanBlog 会阻止并给出提示

  :::

## 标签管理

写文章或草稿时，标签输入框可以一次粘贴多个标签（英文/中文逗号、分号或换行分隔）。空格不会拆开，多词标签（如 `machine learning`）会保持一条。前台文章页底部会显示该文的标签（带标签图标），点标签可进入对应标签页。详见 [文章管理 · 标签](./article.md)。

标签管理位于后台的 `站点管理/数据管理/标签管理`:

![标签管理](https://www.mereith.com/static/img/40e8150b4c40fcdbcb9353bebabf5e1f.clipboard-2022-09-01.png)

<!-- more -->

你可以:

- 查看标签: 可直接跳转到博客的对应页面查看相关标签的文章。

- 重命名: 对标签进行重命名，这会把所有文章原有的标签名都修改为新标签名，其他标签不会变化。

- 删除标签

  此操作会删除所有文章中包含的这个标签，文章中其他的标签不会变化。
